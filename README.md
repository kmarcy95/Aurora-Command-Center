# Aurora - Command Center

Autonomous marketing agency for KM Consulting. Seven AI agents coordinating LinkedIn publishing, recruiter outreach, CRM, and analytics.

**Live:** https://kmarcy95.github.io/Aurora-Command-Center/

## Stack
Single-page static HTML/JS/CSS - no build step. Hosts cleanly on GitHub Pages, Netlify, Vercel, or any static host.

## Files
- index.html - full dashboard (~3000 lines)
- manifest.json - PWA manifest
- service-worker.js - offline cache
- 404.html - SPA-style fallback

Built for KM Consulting - 2026
